❌ Traditional "Castle-and-Moat"

Single-Gate Authentication: Password checked once at login. Once inside, user is trusted forever.

Credential Theft Blindness: If an attacker steals valid credentials, firewalls cannot differentiate them from the real employee.

Passive Defense: Relies on after-the-fact log queries when damage has already been done.

✅ CyberShield Continuous Zero-Trust

Continuous Verification: Every session request, download, and geolocation change is scored in real time.

Dynamic Trust Score (0–100): Trust is a living metric that decays on anomalies and recovers on verified actions.

Active Deception & Adaptive MFA: Honeytoken tripwires and Step-Up challenges intercept attackers autonomously.

Q1: Why did you build this in Python and Flask instead of using a commercial tool like Splunk? ▼
"Commercial tools like Splunk or Elastic are enterprise software aggregators—they search logs, but do not demonstrate algorithmic comprehension. By building CyberShield in Python/Flask from first principles, every component—the Haversine spherical math, the sliding-window state correlation, the deception tripwire, and the dynamic session calculus—is fully auditable, transparent, and has zero external attack surface."
Q2: How does your system prevent false positives and alert fatigue? ▼
"Traditional systems use binary thresholds: one anomaly triggers an immediate ban or alert storm. CyberShield implements the Gartner CARTA framework. Minor anomalies (such as logging in 1 hour later than usual) apply a modest 15-point penalty without interrupting user workflow. Only when cumulative risk breaches the policy threshold (60/100) does the system introduce a frictionless Step-Up MFA challenge."
Q3: Why did you choose the Haversine formula over Euclidean distance? ▼
"Euclidean distance assumes a flat 2D plane. Earth is an oblate spheroid with a mean radius of 6,371 km. Euclidean calculations on latitude and longitude produce severe geographic distortion, especially towards the poles. Haversine calculates true great-circle spherical distance across the curvature of Earth."
Q4: What happens if an insider tries to steal confidential salary files? ▼
"We deployed Active Deception Technology (Honeytokens). Legitimate employees have no operational reason to download decoy files like Confidential_Executive_Salaries_2026.xlsx. Accessing this decoy is a 100% true-positive indicator of malicious intent, justifying instant automated quarantine with 0 trust under MITRE T1204."
Q5: What is your Software 1.0 to 3.0 roadmap for CyberShield? ▼
"Software 1.0 (our current working prototype) uses deterministic, explainable heuristics and mathematical formulas. Software 2.0 will introduce unsupervised Isolation Forests trained on multi-dimensional telemetry vectors. Software 3.0 will incorporate an agentic LLM SOC Copilot that ingests JSON audit logs to produce natural-language incident summaries and automated remediation scripts."
